股票名称清洗说明

数据内容：股票名称变更历史数据（股票代码、公告日期、新名称、变更原因等）

数据频率：不定期更新，当股票发生名称变更时

支持模式：全量清洗（无需日期范围）和增量清洗（需要指定日期范围）

⚙️ 清洗模式
📊 全量清洗：重新清洗所有历史数据，不需要指定日期范围
⚡ 增量清洗：只清洗指定日期范围内的数据，需要设置开始和结束日期
